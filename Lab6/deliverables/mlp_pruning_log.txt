--------------------------------------------------------------------------------
 1. PRUNED MLP DESCRIPTION
--------------------------------------------------------------------------------

The trained model is wrapped layer-by-layer with tfmot `prune_low_magnitude`
(In[257]).  Each Dense/Activation/Flatten layer becomes a `PruneLowMagnitude`
wrapper that adds, per weight tensor:
  * a binary mask  (same shape as the kernel, 1 = keep / 0 = prune)
  * a pruning threshold scalar
  * a step counter
The wrappers roughly double the reported parameter count during training but
add NO trainable parameters - the extra tensors are non-trainable bookkeeping.

pruned_model.summary()  (In[257], Keras "model_2"):

    prune_low_magnitude_act_1                 (None, 5)               1

After training, `strip_pruning` would return a plain 4,135-parameter Dense model
whose kernels contain ~79 % hard zeros.

get_weights() layout of the wrapped model (used in In[257] for the mask read-out):
  index  0,6,12,18  : PruneLowMagnitude bookkeeping / step vars
  index  1,7,13,19  : Dense kernels      (dense_1, dense_2, dense_3, output_layer)
  index  2,8,14,20  : Dense biases       (never pruned)
  index  3,9,15,21  : binary pruning masks (1 = kept, 0 = pruned)
  index  4,5,10,11..: thresholds / step counters

--------------------------------------------------------------------------------
 2. PRUNING ALGORITHM
--------------------------------------------------------------------------------

Magnitude-based pruning with a polynomial-decay sparsity schedule (In[257]):

    batch_size = 32 ; epochs = 10 ; num_images = 60000
    end_step   = ceil(60000 / 32) * 10 = 1875 * 10 = 18750

    pruning_params = {
        'pruning_schedule': tfmot.sparsity.keras.PolynomialDecay(
            initial_sparsity = 0.00,
            final_sparsity   = 0.80,
            begin_step       = 3000,
            end_step         = 18750)
    }

    pruned_model = clone_model(model)                       # fresh weights!
    pruned_model = prune_low_magnitude(pruned_model, **pruning_params)
    pruned_model.compile(optimizer='adam',
                         loss=SparseCategoricalCrossentropy(from_logits=False),
                         metrics=['accuracy'])
    callbacks = [tfmot.sparsity.keras.UpdatePruningStep()]
    history = pruned_model.fit(data_train, label_train,
                               batch_size=32, epochs=10,
                               validation_split=0.20, callbacks=callbacks)

How it works:
  * Every `UpdatePruningStep` callback tick advances the global step.
  * Between begin_step=3000 and end_step=18750 the target sparsity grows along a
    polynomial (exponent 3 by default) from 0 % to 80 %.
  * At each pruning update the |weights| of every Dense kernel are sorted and the
    smallest-magnitude fraction (= current target sparsity) is set to 0 by the
    binary mask; biases are left untouched.
  * The mask is re-applied after every gradient step, so pruned weights stay 0
    while the surviving weights keep training.
  * NOTE: `clone_model` copies only the architecture, so this run trains a
    freshly-initialised network *from scratch while pruning* rather than pruning
    the already-trained model - that is why its accuracy is unstable (see log).

Memory-saving metric used by the notebook (In[257]):
    weights_total   = sum of kernel sizes only  = 3920+40+64+80 = 4104
    weights_pruned_remained = sum(mask)  (non-zero kernel weights that survive)
    saved = (1 - weights_pruned_remained / weights_total) * 100
    -> printed result:  "The saved memory space by pruning is 78.947%"
       => ~864 non-zero kernel weights remain out of 4104
    "The accuracy drop is 17.870%"

The systematic sweep (In[260]) instead prunes the *trained* model
(`prune_low_magnitude(model, ...)`) for a range of final_sparsity values.

    # implement the ReLU activation function
    def ReLU_layer(in_activations):
        out_activations = np.zeros(in_activations.shape)
        for i in range(len(in_activations)):
            if in_activations[i] > 0:
                out_activations[i] = in_activations[i]
        return out_activations

In [239]:
    # implement the softmax activation function
    def softmax_layer(in_activations):
        out_activations = np.zeros(in_activations.shape)
        exp_vals = np.exp(in_activations)
        for i in range(len(in_activations)):
           out_activations[i] = exp_vals[i] / exp_vals.sum()
        return out_activations

    # function to quantize weights with speficied bit width for integer and fractional part
    def fixP_quantization(input_weight, int_BW, frac_BW):
        resolution_ = 2 ** (-frac_BW)           # smallest representable step
        range_       = 2 ** int_BW               # sign bit included → range is [-range_, range_)
        
        weight = deepcopy(input_weight)
        
        input_weight_clipped    = np.clip(weight, -range_, range_ - resolution_)
        input_weight_quantized  = np.round(input_weight_clipped / resolution_) * resolution_
        
        return input_weight_quantized
